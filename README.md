# KLANVISION – Python Full Stack Developer Internship Projects

## Internship Role
Python Full Stack Developer

## Organization
Klanvision Group Industries

## Project Overview

This repository contains two projects developed as part of the Klanvision Python Full Stack Developer Internship.

The projects demonstrate Python backend development, Flask web applications, database integration, frontend development and application management.

## Project 1: Smart Healthcare Appointment Management System

A web-based application that allows patients and doctors to manage healthcare appointments.

### Features
- Patient Registration
- Doctor Management
- Doctor Search
- Appointment Booking
- Appointment Cancellation
- Appointment Status Management
- Appointment History
- Admin, Doctor and Patient Operations
- Input Validation
- Duplicate Appointment Prevention

### Technologies
- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2

Project Folder: `Healthcare-Appointment-System`

## Project 2: Job Portal & Recruitment Management System

A web-based recruitment application that allows candidates to register, companies to manage information and jobs to be published and applied for.

### Features
- Candidate Registration
- Company Management
- Job Posting
- Job Searching
- Job Details
- Resume Upload
- Application Tracking
- Application Status Management
- Admin Dashboard
- Candidate, Company and Job Management
- Input Validation
- Duplicate Application Prevention

### Technologies
- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2

Project Folder: `Job-Portal-Recruitment-System`

## Installation and Execution

Each project has its own requirements.txt file and installation instructions.

Navigate to the respective project folder, create a virtual environment, install dependencies and run the Flask application.

## Purpose

These projects were developed to demonstrate practical full-stack development skills, including frontend development, backend programming, database integration and application functionality.
